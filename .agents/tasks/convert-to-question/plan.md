# Implementation Plan

## Findings and decisions

- CodeGraph was not available in the exposed workspace tools, so navigation used targeted source inspection and symbol searches. The source of truth is `apps/web/lib/convertToQuestion.ts`, `apps/web/lib/clipboardQuestionPrompt.ts`, `apps/web/lib/clipboardParser.ts`, `ManualQuizCreator.tsx`, `QuizQuestionFormModal.tsx`, `QuizOverviewClient.tsx`, `RichTextEditor.tsx`, and their existing Vitest tests.
- The requested `apps/web/lib/ai/clipboardQuestionPrompt.ts` does not exist. The actual prompt module is `apps/web/lib/clipboardQuestionPrompt.ts`; this discrepancy must be preserved in implementation notes rather than creating a duplicate module.
- The reported “term field” issue is not verifiable as a current defect from source alone. The manual quiz metadata `Term / Grading Period` is a native `<select>` plus a custom grading-period input and is intentionally marked `data-skip-clipboard-intercept="true"`; it must remain ordinary metadata entry. The target identification answer/term fields in both authoring flows are the fields that should parse pasted definitions. Browser verification is required to distinguish these meanings.
- Choose one deterministic converter strategy: rewrite answer-bearing clauses in place, never inject a question fragment before the source sentence ends, and append a single final question only when the rewritten result does not already end in `?`. This preserves source wording better than replacing arbitrary matches with `What is this called?`.

## Ordered implementation

Leading `In/With/During/For <term>` openers should become `Here,` for the first occurrence and a contextual continuation such as `We also` for later opener sentences; predicate forms should replace only the answer slot with `what` (for example, `are often called scalars` -> `are often called what`) or use `known as what` without placing a question fragment mid-sentence; later ordinary mentions may become `this process`/`this operation` or be excised only when grammar remains intact. Add one final suffix such as `What is this operation called?` only if the transformed text has no terminal question mark, collapse duplicate generated suffixes, and capitalize only the first alphabetic character of the final result.
